# Tram Nguyen’s portfolio

A static site for GitHub Pages. Open index.html to preview it. HTML, CSS, and local image assets are all the site needs.

## Publish on GitHub Pages

For a separate preview, create a new public GitHub repository such as portfolio. Upload the contents of this folder to the repository root, including index.html, styles.css, assets, and .nojekyll. Commit to main. In Settings → Pages, select Deploy from a branch, main, and /(root), then save. The URL will be  https://tramnguyen1712.github.io/personal-site/ if the repository is named portfolio.

The account already has a tramnguyen1712.github.io repository. To use the root address, keep a copy of the current site and review its publishing configuration before replacing its files. If it publishes through an existing workflow, update the publishing source to the intended branch and root.

## Update the content

Each project is an article in index.html. Add project images to assets and copy the existing gallery figure markup to include a thumbnail, accessible alt text, and caption. Link to the public demo, source code, or write-up in the card. For sponsored work, use approved demo images or sample data. For the contact section, edit the email and profile links in the footer.
